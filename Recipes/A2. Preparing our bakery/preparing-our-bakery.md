## Before we start:
### What's Python?
In the last lesson I said that almost in every lesson I'll use neural networks and other examples to let you all *bakers* understand better and faster, well... How do I make those examples? Ez. Using Python.

Python is a programming language used for a lot of things, it can be used for literally anything, from automatization to data analysis, from software development to, in fact, AI. I chose Python not just because everybody uses it for AI, but because it's simple and easy to understand too! It's not like some complicated language such as C++.

And even if you don't know it yet, you'll learn it really fast. Trust me.

![](/images/A2/1.png)

### What's a code editor?
I know, I'm yapping more about everything you would probably think it's obvious than actually talking about AI, but hey... no *baker* was born as a professional! I need to give some context to align everybody (almost) at the same level, so...

Code editors are the tools used to test, write, change, tweak and manage the code inside a non-compiled (so human-readable) file. That's what you and I will use for all the lessons, examples and exercises, it'll be an essential tool for this journey and it's important to choose and set it up the proper way.

### What code editor we'll use?
Visual Studio Code. One of the best code editors out there, it has everything we'll need and it's customizable. VS code supports Python and some extensions for it that will make our journey easier. I'll do a step-by-step tutorial to download it and set it up later on ([Visual Studio Code](#Visual-Studio-Code:)).

> [!NOTE]
> VS code is not the only solution, there are other tools (called IDE) that are almost like code editors, but have a lot more functionalities. For beginners, stick to VS code. Else, if you're already used to one of them, you can use it. VS code is always suggested but feel free to use whatever you think it's better for you!

### What's Git?
Ever broke your code and couldn't go back? Nightmare. Git is your project's time machine. It saves "snapshots" of your work so you can experiment freely and revert any mistake in a click. It's essential for keeping files organized and collaborating.

![](/images/A2/2.png)

### What's Miniconda?
AI libraries love to fight each other and mess up your computer. Miniconda fixes this by creating isolated "rooms" (environments). You can install Python and specific tools in one room without breaking anything else. Miniconda is actually a lighter version of Anaconda, and with what we're going to do Miniconda is just fine.

![](/images/A2/3.png)
