# AIEasyPie
Hello there, *pie enthusiasts*! Have you ever thought about how everyday AI tools you're using (or just hearing about) actually work? Well, in this repository I'm trying to explain everything about those (not so) magical instruments you deal with everyday, not just simple facts about it or plain explanations, but real demonstrations via small and comprehensible AI "children", talks about the future of those megaminds made out of calculations, and much...MUCH more!

## Introduction:
### What's AIEasyPie?
the idea of this project started as a way to learn more about this whole world behind systems that already took place in almost everything in our lives and to create annoying documentations for an annoying NPC portfolio, but It became a much more interesting idea. The project consists in making you, all the *bakers* out there and me able to learn something and share our opinions about AI and it's future. AIEasyPie is not just a simple repository, it's a journey. So hop on and enjoy the ride!

### Is this some kind of joke?
You would probably say. Well, no. It looks different because it **is** different. I understood with time that for some people that has just started learning in fields like computer engineering and AI, understanding other people's lessons or documents (ESPECIALLY on Github) is something far more than impossible. This project is meant for that kind of people too. Yea, it's literally for everyone. It's meant for everyone. No secret recipes, just baking. So a more friendly tone, plus the others characteristics of this project are in my opinion the perfect cocktail for clarity and understanding.

### Ok then, is it open-source?
Of course! No license, no paid bullpie or things like this. As said, it's meant for everyone and everyone can contribute!

### How do I access the oven?
Now, let's get into it. You'll find a folder, packed with documents. Don't worry, I sorted all of them so you don't get lost inside the folders, everything is in chronological order. Just follow the folders' order and you're good to go!
